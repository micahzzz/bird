General Site Settings

The name of your station, which will be displayed on the local web interface and used for services like BirdWeather.
Your station's north-south geographic coordinate. Used for species range calculations and weather data.
Your station's east-west geographic coordinate. Used for species range calculations and weather data.
Your local timezone (e.g., 'America/New_York'). This ensures all timestamps for detections and reports are accurate.

Disk Management

Determines what the system should do when the disk reaches its usage threshold. 'Purge' will delete the oldest recordings to free up space. 'Keep' will stop the recording and analysis services to prevent further disk usage.
The disk usage percentage that will trigger the 'Full Disk Behavior'. For example, if set to 90, the system will act when the disk is 90% full.
The maximum number of recording files to keep for any single species. Once this limit is reached, the oldest recording for that species will be deleted to make room for a new one. Set to 0 for unlimited.

Audio Settings

The ALSA identifier for your microphone (e.g., 'hw:1,0'). 'Default' usually works, but specify if you have multiple sound cards.
Set to 1 for mono microphones or 2 for stereo.
The duration of each individual audio recording chunk in seconds. 15 seconds is a common default.
The length of the audio segment (in seconds) to extract from a recording when a bird is detected. This must be less than or equal to the Recording Length.
Applies a high-pass filter to the audio, removing frequencies below this value (in Hz). Useful for cutting out low-frequency noise like wind or traffic rumble. Set to 0 to disable.
The file format for saved recordings. 'wav' is lossless but uses more space. 'mp3' is compressed and saves space.

Analysis & Model Settings

The machine learning model used for species identification. Different models may have different geographic coverage or performance characteristics.
A confidence score between 0 and 1. Detections with a score below this 'species validation' threshold but above the main 'confidence' threshold are logged but marked as uncertain. It acts as a secondary filter for very high confidence sightings.
If a species has not been detected for this many days, its next detection will be marked as 'Rare' in the interface.
For developers. If 'true', saves an unprocessed, raw spectrogram image alongside the standard one.

Notification Settings

Enter your Apprise service URLs here, one per line. Apprise supports over 80 notification services including Email, Pushbullet, Telegram, etc.
The title of the notification message. You can use variables like $comname, $sciname, and $confidence.
The main content of the notification message. Supports the same variables as the title.
To prevent spam, this sets the minimum time in seconds before another notification for the same species will be sent.
If checked, a notification will be sent for every single detection that meets the confidence threshold (respecting the cooldown).
Sends a notification only the very first time a species is ever detected by your station.
Sends a notification the first time a species is detected on any given day.
If checked, a weekly summary report of all detections will be sent via your Apprise services.
A whitelist. If this list is not empty, notifications will ONLY be sent for species on this list. One species name per line.
A blacklist. Notifications will NEVER be sent for any species on this list, regardless of other settings. One species name per line.
